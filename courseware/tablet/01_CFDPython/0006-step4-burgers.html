1 · 数学物理基石：非线性陡化、黏性耗散与 Cole-Hopf 变换

1.1 对立统一的物理博弈：雷诺数的几何直觉

在 Burgers 方程中，非线性项 $u \partial_x u$ 具有“大速度跑得快、小速度跑得慢”的自加速特性，波峰会不断追赶波谷，导致波前梯度 $\partial_x u o -\infty$。如果没有扩散，波形将在有限时间内发生多值重叠（Breaking），形成数学上的间断激波。

而右侧的粘性项 $ u \partial_{xx} u$ 则由微观分子碰撞产生，当空间二阶导数极度剧烈时，粘性耗散通量成倍暴增，强行阻止波形坍缩为无穷薄的间断，将其稳定在具有特定物理厚度 $\delta \sim u / \Delta u$ 的粘性激波层（Viscous Shock Profile）内部。

两者强度的无量纲比值即为局部雷诺数：

$$\mathrm{Re} = \frac{\text{对流惯性项}}{\text{粘性扩散项}} \sim \frac{U L}{\nu}$$

当 $\nu \to 0$ 时，$\mathrm{Re} \to \infty$，解趋近于无粘间断激波；当 $\nu$ 较大时，扩散彻底驯服对流，系统演化为光滑的衰减波包。

1.2 Cole-Hopf 严格线性化变换

1950 年代，Julian Cole 与 Eberhard Hopf 独立发现了一个奇迹般的非线性代换。令：

$$u(x, t) = -2\nu \frac{1}{\phi(x, t)} \frac{\partial \phi(x, t)}{\partial x} = -2\nu \frac{\partial \ln \phi}{\partial x}$$

将此式代入一维粘性 Burgers 方程，经过求导链式法则展开，极其繁杂的非线性交叉项相互完全抵消，原方程奇迹般地退化为关于辅助变量 $\phi$ 的标准一维线性热传导方程：

$$\frac{\partial \phi}{\partial t} = \nu \frac{\partial^2 \phi}{\partial x^2}$$

利用热传导方程已知的泊松积分核或周期级数解，我们便可以通过纯解析方式获得 Burgers 方程在任意时刻 $t$ 的精确解析解 $u(x, t)$！本章采用的经典初值形式为：

$$\phi(x, 0) = \exp\left(-\frac{x^2}{4\nu}\right) + \exp\left(-\frac{(x - 2\pi)^2}{4\nu}\right)$$ $$u(x, 0) = -\frac{2\nu}{\phi} \frac{\partial \phi}{\partial x} + 4$$

2 · 慢动作离散化：FTBS-CS 格式与周期环拓扑

我们对时间导数采用一阶前向差分，对非线性对流项采用一阶向后迎风差分（由于平均波速 $u > 0$），对二阶扩散项采用二阶中心差分：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} + u_i^n \frac{u_i^n - u_{i-1}^n}{\Delta x} = \nu \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2}$$

移项整理出显示推进显式更新法则：

$$u_i^{n+1} = u_i^n - u_i^n \frac{\Delta t}{\Delta x} (u_i^n - u_{i-1}^n) + \nu \frac{\Delta t}{\Delta x^2} (u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

周期性边界条件（Periodic Boundary Conditions）

本章计算域设为环形管道 $[0, 2\pi]$。从右侧 $x = 2\pi$ 流出的流体必须在同一时刻从左侧 $x = 0$ 重新流入。这意味着空间拓扑是一个首尾相接的闭合圆环：

$$u_0^n \equiv u_{N-1}^n, \quad u_{-1}^n \equiv u_{N-2}^n, \quad u_N^n \equiv u_1^n$$

在代码实现中，左端点 $i=0$ 的左邻居是倒数第二个物理格点 u[-2]，而计算完成后必须强制使边界值同步闭合：u[-1] = u[0]。

3 · 工业级最小自包含实现

import numpy as np
import sympy as sp
import matplotlib.pyplot as plt

# 1. SymPy 符号代数解析推导初值场
x_sym, nu_sym, t_sym = sp.symbols('x nu t')
phi_sym = (sp.exp(-(x_sym - 4*t_sym)**2 / (4*nu_sym*(t_sym + 1))) +
           sp.exp(-(x_sym - 4*t_sym - 2*sp.pi)**2 / (4*nu_sym*(t_sym + 1))))
phiprime_sym = phi_sym.diff(x_sym)
u_exact_sym = -2 * nu_sym * (phiprime_sym / phi_sym) + 4
# 烘焙为可调用的高性能向量化数值函数
u_exact_func = sp.lambdify((t_sym, x_sym, nu_sym), u_exact_sym, 'numpy')

# 2. 离散网格与物理参数设置
nx = 101
dx = 2 * np.pi / (nx - 1)
nu = 0.07
nt = 100
dt = dx * nu  # 确保扩散与对流稳定性

x = np.linspace(0, 2 * np.pi, nx)
u = u_exact_func(0, x, nu)  # t=0 时刻初始场

# 3. 显式时间步进求解器
for n in range(nt):
    un = u.copy()
    # 内部点向量化更新 (1 到 nx-2)
    u[1:-1] = (un[1:-1] - 
               un[1:-1] * (dt / dx) * (un[1:-1] - un[:-2]) + 
               nu * (dt / dx**2) * (un[2:] - 2 * un[1:-1] + un[:-2]))
    
    # 周期边界更新 (点 0 的左邻居是 un[-2])
    u[0] = (un[0] - 
            un[0] * (dt / dx) * (un[0] - un[-2]) + 
            nu * (dt / dx**2) * (un[1] - 2 * un[0] + un[-2]))
    u[-1] = u[0]  # 闭合圆环端点

# 4. 解析基准比对
u_analytical = u_exact_func(nt * dt, x, nu)
l2_err = np.linalg.norm(u - u_analytical) / np.linalg.norm(u_analytical)
print(f"Burgers FTBS-CS Relative L2 Error: {l2_err:.4e}")
参数 / 语法物理数学含义典型值敏感性分析与工程防错
nu = 0.07运动粘性系数 $\nu$0.07决定激波过渡层厚度；$\nu$ 越小激波越陡，数值振荡风险越剧烈。
dt = dx * nu自适应安全时间步长$\approx 0.0044$同时满足对流 CFL $\le 1$ 与扩散稳定性 $r \le 0.5$ 双重红线。
u[-2] 作为左邻周期间隔负向环绕索引下标 nx-2充分利用 Python 负索引特性；若误写为 u[-1] 则导致零梯度伪边界。
sp.lambdify符号解析式转数值核'numpy' 后端在微秒级完成全网格高效求值，规避慢速 Python 解释循环。

▸ 查看故障根因分析与修复代码

【问题行】：t = 0 变量名被整型数字覆盖！

【失效机理】：在执行 t = 0 之前，t 是 SymPy 的代数符号对象 Symbol('t')；执行后，t 变成了 Python 原生整数 0。在字典 subs={t: n*dt} 中，键变成了 0 而不是符号对象 Symbol('t')！SymPy 在表达式 u_exact 中找不到名为 0 的未知符号，因此完全不执行任何代换，永远返回包含未定符号的解析式或报错崩溃！

【修复代码】：

t_sym = sp.symbols('t')  # 符号必须与数值变量严格命名隔离
t_val = 0.0

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当粘性 $\nu \to 0$ 时，Burgers 方程退化为无粘非线性守恒律 $\partial_t u + u\partial_x u = 0$，特征线发生几何相交，传统微积分强解不复存在，必须引入弱解（Weak Solution）与 Rankine-Hugoniot 激波跳跃条件。
  • 极限二（趋近无穷大时）：当粘性 $\nu \to \infty$ 时，对流惯性项微不足道，系统退化为纯线性扩散传热，初始无论多么剧烈的波形都会在瞬息之间被无差别熨平为一条水平线。
  • 极限三（物理尺度崩溃）：现实气体的激波内部厚度通常只有几个微米（约几个分子平均自由程）。在激波层内部，流体已经处于强非平衡态，Navier-Stokes 与 Burgers 的牛顿剪切应力正比于应变率的线性假设实际上已经濒临失效。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么很多人在写一维周期性边界条件时，写了 u[0] = u[-1] 却发现算着算着质量就莫名其妙地衰减或者失守？

【真实底层】：因为空间格点剖分 $[0, 2\pi]$ 时，端点 $0$ 与 $2\pi$ 物理上是同一个点！如果数组长度为 $N$，则独立物理自由度只有 $N-1$ 个。在更新完成后，正确的边界强制是 u[-1] = u[0]（或者 u[0] = u[-1] 同步）。如果把 u[-1] 当成了独立格点去参与差分计算，就相当于凭空在圆环上硬塞进了一个宽度为 $\Delta x$ 的虚拟泄漏缝隙！
