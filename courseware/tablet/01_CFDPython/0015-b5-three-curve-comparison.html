2 · 慢动作离散化：三线同屏严密对齐代码

import numpy as np
import torch
import matplotlib.pyplot as plt

# 1. 物理参数与解析精确基准
m, mu, k = 1.0, 0.4, 4.0
gamma = mu / (2 * m)
omega = np.sqrt(k / m - gamma**2)
def exact_solution(t):
    return np.exp(-gamma * t) * np.cos(omega * t)

# 2. 经典有限差分 FDM 求解 (dt=0.01)
t_max = 5.0
dt = 0.01
nt = int(t_max / dt) + 1
t_fdm = np.linspace(0, t_max, nt)
u_fdm = np.zeros(nt)
v_fdm = np.zeros(nt)
u_fdm[0] = 1.0; v_fdm[0] = 0.0  # 初始条件

for n in range(nt - 1):
    # 前向显式推进
    a_n = (-mu * v_fdm[n] - k * u_fdm[n]) / m
    v_fdm[n + 1] = v_fdm[n] + a_n * dt
    u_fdm[n + 1] = u_fdm[n] + v_fdm[n] * dt

# 3. 加载/评估训练完毕的 PINN 模型 (在 dense grid 上评测)
t_eval = torch.linspace(0, t_max, nt)[:, None]
# 假设 model 为上一章训练完毕的 PINN
# u_pinn = model(t_eval).detach().numpy().flatten()
u_exact = exact_solution(t_fdm)

# 4. 计算全域相对 L2 范数误差
err_fdm = np.linalg.norm(u_fdm - u_exact) / np.linalg.norm(u_exact)
# err_pinn = np.linalg.norm(u_pinn - u_exact) / np.linalg.norm(u_exact)
print(f"FDM Relative L2 Error: {err_fdm:.4e}")
评估口径标准数学公式典型数值工程意义
相对 $L_2$ 范数误差$ rac{\|\mathbf{u}_{ ext{pred}} - \mathbf{u}_{ ext{true}}\|_2}{\|\mathbf{u}_{ ext{true}}\|_2}$$< 5 imes 10^{-2}$消除物理场绝对量纲影响，国际 SciML 统一裁判指标。
最大绝对误差 $L_\infty$$\max |u_{ ext{pred}} - u_{ ext{true}}|$$< 0.08$探测局域最大极值偏离与激波过渡层畸变。
能量守恒相对漂移$|E(T) - E_{ ext{exact}}(T)| / E_0$$< 2 imes 10^{-2}$检验长时序动力系统的哈密顿量保真度。

4.2 极端参数极限三问（Extreme Limits）

  • 极限一（维度推向 100 维时）：空间维度推升至 100 维（如量子多体或高维随机偏微分方程）时，网格法需要 $100^{100}$ 个点，经典物理彻底灭亡；根据 Barron 逼近定理，神经网络的逼近误差与空间维度 $d$ 无关，成为人类唯一的数值解算突破口！
  • 极限二（噪声鲁棒性极限）：当物理传感器测量数据混入 10% 的高斯随机白噪声时，纯多项式拟合会剧烈震荡被噪声带偏；而 PINN 凭借物理方程算子的刚性约束，能自动过滤噪声充当最优物理低通滤波器。
  • 极限三（相图轨迹闭合性）：在保守系统（如无阻尼摆）中，仅看时序误差是不够的，必须检查相图（Phase Space Trajectory $(u, v)$）的闭合性。传统显式格式可能会出现伪能量漂移，而保辛神经结构能严格保持轨道拓扑闭合。

4.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：很多论文声称“PINN 只需要训练一次，之后推理极快”，这种说法在偏微分方程正向求解中是一个巨大的误导谎言，为什么？

【真实底层】：因为标准 PINN 是逐实例求解（Instance-specific Solver）！如果改变了初始条件 $u(0)=2.0$ 或者改变了边界温度，PINN 原本学到的网络权重就全部作废了，你必须重新随机撒点、重新训练几千步！它并没有学会“从初值到解的映射算子”。真正能做到“训练一次、任意初值秒级推理”的技术，必须升级为神经算子（Neural Operator，如 DeepONet 与 FNO）！这正是我们卷四要探索的终极巅峰。
