1 · 数学与物理基石：二维特征线、合成对流与各向异性

考虑二维标量场 $u(x, y, t)$。当对流速度场为常矢量 $\mathbf{c} = (c_x, c_y)$ 时，方程为：

$$\frac{\partial u}{\partial t} + \mathbf{c} \cdot \nabla u = 0$$

沿着空间三维时空曲线 $(x(t), y(t), t)$，根据全导数链式法则：

$$\frac{d u(x(t), y(t), t)}{dt} = \frac{\partial u}{\partial t} + \frac{dx}{dt} \frac{\partial u}{\partial x} + \frac{dy}{dt} \frac{\partial u}{\partial y} = 0$$

对比两式可知，当空间轨道满足参数方程：

$$\frac{dx}{dt} = c_x, \quad \frac{dy}{dt} = c_y \implies x - c_x t = C_1, \quad y - c_y t = C_2$$

二维特征线是一簇空间中倾斜的平行特征圆柱面（或射线束）！初始时刻在 $(x_0, y_0)$ 处的物理量，在时刻 $t$ 将毫无损失地平移到 $(x_0 + c_x t, y_0 + c_y t)$ 处。

2 · 慢动作离散化：二维迎风格式与多维 CFL 约束

2.1 二维象限迎风差分模板

设速度分量均大于零：$c_x > 0, c_y > 0$。这意味着物理信息同时从流场的左侧（上游 $x$ 方向）和下侧（上游 $y$ 方向）涌入点 $(x_i, y_j)$。因此必须在两个空间方向同时采用向后差分：

$$\frac{u_{i,j}^{n+1} - u_{i,j}^n}{\Delta t} + c_x \frac{u_{i,j}^n - u_{i-1,j}^n}{\Delta x} + c_y \frac{u_{i,j}^n - u_{i,j-1}^n}{\Delta y} = 0$$

解出未来时刻 $u_{i,j}^{n+1}$：

$$u_{i,j}^{n+1} = u_{i,j}^n - c_x \frac{\Delta t}{\Delta x} (u_{i,j}^n - u_{i-1,j}^n) - c_y \frac{\Delta t}{\Delta y} (u_{i,j}^n - u_{i,j-1}^n)$$

2.2 多维 CFL 稳定判据的几何本质

定义各方向 Courant 数：$\sigma_x = c_x \frac{\Delta t}{\Delta x}, \sigma_y = c_y \frac{\Delta t}{\Delta y}$。将上式改写为凸组合形式：

$$u_{i,j}^{n+1} = (1 - \sigma_x - \sigma_y) u_{i,j}^n + \sigma_x u_{i-1,j}^n + \sigma_y u_{i,j-1}^n$$

为保证离散系统服从正保真性（Positivity Preserving）且不引入虚假高频自激振荡，所有基底系数必须非负！由此直接导出：

$$1 - \sigma_x - \sigma_y \ge 0 \implies \sigma_x + \sigma_y \le 1$$

★ 致命陷阱：在一维中，只要 $\sigma \le 1$ 即可稳定；但在二维正方形网格（$c_x=c_y, \Delta x=\Delta y$）下，单方向 Courant 数必须满足：$\sigma \le 0.5$！多维度的信息叠加，将安全时间步长的允许上限直接腰斩！

3 · 工业级最小自包含实现

import numpy as np
import matplotlib.pyplot as plt

# 1. 二维网格与时间步长配置
nx, ny = 81, 81
Lx, Ly = 2.0, 2.0
dx = Lx / (nx - 1)
dy = Ly / (ny - 1)
c_x, c_y = 1.0, 1.0

# 满足 2D CFL 条件: sigma_x + sigma_y <= 0.6
sigma = 0.3
dt = sigma * min(dx / c_x, dy / c_y)
nt = 50

# 2. 构造 2D 方帽初值
x = np.linspace(0, Lx, nx)
y = np.linspace(0, Ly, ny)
X, Y = np.meshgrid(x, y)
u = np.ones((ny, nx))
u[int(0.5 / dy):int(1.0 / dy + 1), int(0.5 / dx):int(1.0 / dx + 1)] = 2.0

# 3. 二维切片零循环时间步进
for n in range(nt):
    un = u.copy()
    # 注意二维矩阵切片: u[行y, 列x]
    u[1:, 1:] = (un[1:, 1:] - 
                 c_x * (dt / dx) * (un[1:, 1:] - un[1:, :-1]) - 
                 c_y * (dt / dy) * (un[1:, 1:] - un[:-1, 1:]))
    # 狄利克雷边界固定
    u[0, :] = 1.0
    u[-1, :] = 1.0
    u[:, 0] = 1.0
    u[:, -1] = 1.0

print(f"2D Convection completed. Mass integral: {np.sum(u)*dx*dy:.4f}")
参数 / 语法物理数学含义典型值敏感性分析与工程防错
u[1:, 1:]内部待更新场点矩阵形状 (ny-1, nx-1)行对应 $y$ 坐标，列对应 $x$ 坐标；切勿搞反行列顺序。
un[1:, :-1]沿 $X$ 轴向左偏移格点 $(i-1, j)$与待更新区形状对齐利用切片实现 $x$ 轴一阶迎风，无任何原生 Python 慢循环。
un[:-1, 1:]沿 $Y$ 轴向下偏移格点 $(i, j-1)$与待更新区形状对齐利用切片实现 $y$ 轴一阶迎风，耗时极短。
sigma = 0.3各向安全 Courant 因子0.3和为 $0.6 < 1.0$，严格处于二维稳定三角安全区内部。

4.3 单步离散手算推演（Trace the Path）

◆ 纸笔手算心智模型对齐

【初始二维离散状态】：取 $3 \times 3$ 局部小网格，时刻 $n$ 时 $u$ 场分布为：
行 0 (y=0): [1.0, 1.0, 1.0]
行 1 (y=1): [1.0, 2.0, 1.0]
行 2 (y=2): [1.0, 1.0, 1.0]
速度 $c_x = 1.0, c_y = 1.0, \Delta x = \Delta y = 1.0, \Delta t = 0.2$。

【手动推演任务】：求内部中心格点 $(i=1, j=1)$ 在时刻 $n+1$ 的离散解 $u_{1,1}^{n+1}$。

▸ 查看单步推演标准数值解答
1. Courant 数：$\sigma_x = 1.0 \times 0.2 / 1.0 = 0.2, \sigma_y = 0.2$；
2. 凸组合系数：$1 - \sigma_x - \sigma_y = 1 - 0.2 - 0.2 = 0.6$；
3. 上游格点值：左邻居 $u_{0,1}^n = 1.0$（同行前一列），下邻居 $u_{1,0}^n = 1.0$（同列前一行）；
4. 代入更新：$u_{1,1}^{n+1} = 0.6 \times 2.0 + 0.2 \times 1.0 + 0.2 \times 1.0 = 1.2 + 0.2 + 0.2 = 1.6$。
物理直觉验证：中心格点的高值 2.0 正在向右上方流失，同时吸收了来自左方和下方的低背景值 1.0，自身幅值平滑衰减至 1.6！

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

一位学生编写了如下二维迎风对流代码，结果波包不仅没有沿对角线平移，反而沿着 $y$ 轴被横向拉扯成诡异的面条：

# 错误代码：行列索引混淆
for n in range(nt):
    un = u.copy()
    # 试图计算 x 方向差分与 y 方向差分
    u[1:, 1:] = (un[1:, 1:] - 
                 c_x * dt/dx * (un[1:, 1:] - un[:-1, 1:]) -   # BUG!
                 c_y * dt/dy * (un[1:, 1:] - un[1:, :-1]))    # BUG!

【排错审问任务】：指出哪两行代码颠倒了空间方向？指出切片中轴（axis 0 与 axis 1）与物理坐标 $(x, y)$ 的映射法则。

▸ 查看故障根因分析与修复代码

【问题行】：两行差分切片完全颠倒！

【失效机理】：在 NumPy 二维数组中，第一个索引轴 axis 0 遍历行（沿竖直 $y$ 方向变动），第二个索引轴 axis 1 遍历列（沿水平 $x$ 方向变动）！un[:-1, 1:] 改变的是第 0 轴（行），对应的是 $y$ 方向邻居；而 un[1:, :-1] 改变的是第 1 轴（列），对应的是 $x$ 方向邻居！把 $y$ 导数乘上了 $c_x$，把 $x$ 导数乘上了 $c_y$，物理动量方向彻底错乱！

【修复代码】：

u[1:, 1:] = (un[1:, 1:] - 
             c_x * (dt / dx) * (un[1:, 1:] - un[1:, :-1]) - 
             c_y * (dt / dy) * (un[1:, 1:] - un[:-1, 1:]))

▸ 查看费曼级满分通俗解答范例
“如果风只往东吹，一秒钟羽毛只向隔壁房间挪动一步；但如果风同时往东又往北吹，它在这一秒内其实是斜着向东北方向狂奔。如果你记录羽毛位置的相机快门按得太慢，羽毛在一次抓拍间隔里就会连跨好几个地砖格子，彻底从相机的监控视野里飞丢出界，整张轨迹照片就彻底乱套了。”

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当某个速度分量归零（如 $c_y = 0$）时，$\sigma_y = 0$，二维格式严格无缝退化为标准一维迎风对流格式，二维波包退化为一维柱面波。
  • 极限二（各向异性极限）：当网格严重畸变，如 $\Delta x \ll \Delta y$ 时，全局时间步长将被最小间距 $\Delta x$ 极度扼杀，即使 $y$ 方向流动非常平缓，整体计算效率也会被极度拖垮（刚性网格问题）。
  • 极限三（物理旋转不变量）：如果坐标系旋转 45 度，真实物理场保持各向同性不变；但一阶笛卡尔迎风格式会产生严重的网格对齐人工耗散——沿坐标轴平移变形小，沿对角线平移变形最严重。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么很多人在写 2D 绘图时，调用 plt.imshow(u) 会发现图像与物理流场上下颠倒了 180 度？

【真实底层】：因为计算机图像坐标系原点 $(0,0)$ 默认在屏幕左上角，第 0 轴正方向是向下；而笛卡尔物理坐标系原点在左下角，$y$ 轴正方向是向上！如果不显式添加 origin='lower'，你的流体就是在重力倒错的倒立宇宙中运行！这是无数工程可视化事故的根源。
