1 · 数学与工程基石：符号自适应迎风通量分裂

1.1 为什么天真的一阶差分在批量产数据时必炸？

在卷一第 02 章中，我们推导的一阶迎风格式是向后差分：$-u_i (u_i - u_{i-1}) / \Delta x$。但那是建立在流速恒正（$u > 0$ 永远从左向右吹）的理想前提下！

在为算子学习生成数据时，初始场是由高斯随机场（GRF）生成的波动场，流速必然在某些区域向右（$u > 0$），在另一些区域向左（$u < 0$）！如果无脑使用向后差分，在负速度区向后差分就变成了下风格式（Downwind Scheme）！其数值耗散为负，局域能量以指数级自发爆炸，导致生成的 10,000 条轨迹中有 60% 在运行中途直接溢出为 NaN 废品！

1.2 Murman-Cole 迎风通量分裂算法

工业级数据生成器必须具备正负速度自适应感知能力：

$$\left( u rac{\partial u}{\partial x} ight)_i pprox u_i^+ rac{u_i - u_{i-1}}{\Delta x} + u_i^- rac{u_{i+1} - u_i}{\Delta x}$$

其中正向速度分量 $u_i^+ = \max(u_i, 0)$，负向速度分量 $u_i^- = \min(u_i, 0)$！

无论流体在局部如何倒流或反复打转，该代数分裂格式在数学上保证了局域数值粘性恒定非负，从第一性原理层面彻底歼灭了批量数据生成的爆炸隐患！

2 · 慢动作代码实现：端到端数据生成与算子闭环

import numpy as np
import torch
import torch.nn as nn
from neuralop.models import TFNO

# 1. 工业级 FDM 数据生成器 (带符号自适应迎风通量)
def generate_burgers_fdm_trajectory(nx=64, nt=100, nu=0.01, seed=42):
    np.random.seed(seed)
    dx = 1.0 / nx
    dt = 0.001
    x = np.linspace(0, 1, nx, endpoint=False)
    
    # 构造随机平滑多频初值场
    u = np.sin(2 * np.pi * x) + 0.5 * np.sin(4 * np.pi * x) + 0.2 * np.random.randn(nx)
    u_initial = u.copy()
    
    for n in range(nt):
        # 1.1 周期边界环绕差分
        du_backward = (u - np.roll(u, 1)) / dx
        du_forward  = (np.roll(u, -1) - u) / dx
        
        # 1.2 Murman-Cole 符号自适应迎风通量
        advection = np.maximum(u, 0) * du_backward + np.minimum(u, 0) * du_forward
        diffusion = nu * (np.roll(u, -1) - 2 * u + np.roll(u, 1)) / (dx ** 2)
        
        # 显式步进
        u = u - dt * advection + dt * diffusion
        
    return u_initial, u

# 2. 批量生产 100 条高保真物理轨迹
print("Generating 100 FDM trajectories with Murman-Cole flux...")
data_in, data_out = [], []
for i in range(100):
    u_0, u_T = generate_burgers_fdm_trajectory(seed=i)
    data_in.append(u_0)
    data_out.append(u_T)

data_in = torch.tensor(np.array(data_in), dtype=torch.float32).unsqueeze(1)
data_out = torch.tensor(np.array(data_out), dtype=torch.float32).unsqueeze(1)

# 3. ★ 工业数据契约严格校验 (防范脏数据污染模型)
assert not torch.isnan(data_in).any(), "NaN found in input data!"
assert not torch.isnan(data_out).any(), "NaN found in output data!"
print("Data contract verification passed 100%!")

# 4. FNO 神经算子学习会师训练
fno_operator = TFNO(n_modes=(16,), hidden_channels=64, in_channels=1, out_channels=1)
optimizer = torch.optim.Adam(fno_operator.parameters(), lr=1e-3)
criterion = nn.MSELoss()

for epoch in range(100):
    optimizer.zero_grad()
    pred = fno_operator(data_in)
    loss = criterion(pred, data_out)
    loss.backward()
    optimizer.step()

print(f"Grand Convergence! FNO learned operator from FDM data. Final Loss: {loss.item():.4e}")
