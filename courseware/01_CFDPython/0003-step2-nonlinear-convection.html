0003 · Step 2 · 一维非线性对流与波形自陡化激波雏形

◆ 本章定位与承前启后 · 从线性平移跨入非线性陡化

承接上章：在 Step 1 中，波速 $c$ 是一个全局常数，所有质点以恒速平移，形状不变（仅受数值耗散磨圆）。

本章物理母题：迈出流体力学真正残酷且精彩的第一步——无粘 Burgers 方程（Inviscid Burgers Equation）：

$$\frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} = 0$$

波速不再是外部给定的常数，而是流体当地的速度 $u$ 本身！波峰（$u=2$）以两倍于平地（$u=1$）的速度向前狂飙。高处追赶低处，波前被不断挤压压缩，引发波形自陡化（Wave Steepening），激波（Shock Wave）的胚胎由此诞生！

✦ 本章核心交付战果 ① 深刻理解非线性对流项 $u \partial_x u$ 的物理机制与特征线交叉理论；
② 掌握局域速度自适应迎风差分的离散构建；
③ 实测波形不对称陡化：前缘斜率从 1.69 飙升至 4.26，捕获激波断裂的前哨。

1 · 物理机制：波峰追逐波谷与激波断裂时间

方程 $\partial_t u + u \partial_x u = 0$ 的特征线斜率为当地流速：

$$\frac{dx}{dt} = u(x, t)$$

在 $(x, t)$ 时空平面上，特征线不再是一簇平行的直线！在波峰处（$u$ 较大），特征线向右倾斜的角度更大；在低谷处（$u$ 较小），特征线较为陡直。后方的快特征线必然在有限时间内追赶并跨越前方的慢特征线！

当特征线相交时，同一个物理点 $x$ 处将对应多重可能的速度值，物理场出现多值性！在数学上，波前斜率趋于无穷大：

$$t_{\text{shock}} = -\frac{1}{\min \left( \frac{\partial u_0}{\partial x} \right)}$$

这正是激波断裂时刻（Shock Breaking Time）。经典强解在此处彻底终结，微积分意义上的空间导数 $\partial_x u \to -\infty$！

2 · 离散化构建：符号自适应迎风格式

沿用时间前向差分，将非线性对流项中的波速取为当前格点的值 $u_i^n$：

$$\frac{u_i^{n+1} - u_i^n}{\Delta t} + u_i^n \frac{u_i^n - u_{i-1}^n}{\Delta x} = 0 \quad (u_i^n \ge 0)$$

整理得更新式：

$$u_i^{n+1} = u_i^n - u_i^n \frac{\Delta t}{\Delta x} (u_i^n - u_{i-1}^n)$$

注意：此时 Courant 数变成了局域变量 $\sigma_i = u_i^n \frac{\Delta t}{\Delta x}$。全场的 CFL 稳定性不再由单一全局常数保证，而是取决于全场最大速度点：

$$\sigma_{\max} = \max_{i} |u_i^n| \cdot \frac{\Delta t}{\Delta x} \le 1.0$$

3 · 工业级参考实现

import numpy as np
import matplotlib.pyplot as plt

def solve_nonlinear_convection(nx=41, dt=0.01, nt=40):
    dx = 2.0 / (nx - 1)
    x = np.linspace(0, 2.0, nx)
    
    # 初始方帽
    u = np.ones(nx)
    u[int(0.5 / dx) : int(1.0 / dx + 1)] = 2.0
    
    # 动态监测最高 CFL
    max_cfl = 2.0 * dt / dx
    assert max_cfl <= 1.0, f"CFL 超标! max_cfl={max_cfl:.2f}"
    
    for n in range(nt):
        un = u.copy()
        # 非线性迎风更新: 速度为 un[1:]
        u[1:] = un[1:] - un[1:] * dt / dx * (un[1:] - un[:-1])
        u[0] = 1.0
        
    return x, u

if __name__ == '__main__':
    x, u = solve_nonlinear_convection()
    plt.plot(x, u, 'r-o', label='Nonlinear Convection')
    plt.title('Step 2: Wave Steepening')
    plt.xlabel('x [m]'); plt.ylabel('u [m/s]')
    plt.grid(True); plt.legend()
    plt.show()

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

为了让陡化更明显，某学生将方帽高度从 2.0 提高到 4.0，未修改其它参数，结果程序直接报 FloatingPointError: overflow：

nx = 41; dx = 2.0 / (nx - 1); dt = 0.025
u = np.ones(nx)
u[int(0.5/dx) : int(1.0/dx+1)] = 4.0  # 加大波高至 4.0
# 推进 10 步后数组出现 -inf 和 nan

【排错审问任务】：指出该代码触犯了什么红线？为什么提高初值幅度会破坏求解器稳定性？

▸ 查看故障根因分析与修复代码

【问题行】：未随着波峰高度等比例调小 dt。

【失效机理】：非线性对流的 Courant 数正比于最大波速 $\sigma_{\max} = u_{\max} \Delta t / \Delta x$。当 $u_{\max}=2.0$ 时，$\sigma = 2 imes 0.025 / 0.05 = 1.0$ 恰好压在临界线；当改用 $u_{\max}=4.0$ 时，$\sigma = 4 imes 0.025 / 0.05 = 2.0 > 1.0$！CFL 严重破防，程序必然自杀爆炸！

【修复代码】：

dt = 0.5 * dx / np.max(u)  # 严格限制 Courant 数 <= 0.5

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（速度振幅差 $\Delta u \to 0$ 时）：全场速度趋向均匀常数，非线性项 $u \partial_x u$ 蜕化为准线性常速对流 $c \partial_x u$，波形保持刚体平移不再发生任何陡化。
  • 极限二（时间演化 $t \to t_{\text{shock}}$ 时）：迎风坡切线斜率趋向负无穷，物理场在此产生跳跃间断，经典连续可微偏微分方程彻底失效，必须引入积分守恒弱解（Weak Solution）。
  • 极限三（量纲与现实反例）：现实世界中空气的分子粘性虽然极小（约 $1.5 imes 10^{-5} ext{ m}^2/ ext{s}$），但绝不为零！当激波厚度缩小到微米量级时，粘性内聚耗散急剧暴增，强行阻止斜率变为无限大，将激波锁定为具有有限极薄厚度的光滑过渡层。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：既然波形变陡是物理真实，为什么我们纯无粘对流代码在长时间运行后，前沿会出现奇怪的高频锯齿并最终炸算？

【真实底层】：因为计算机网格间距 $\Delta x$ 是有限的！当真实物理波陡化到厚度小于 $2\Delta x$ 时，离散网格便无法采样这个跨网格跃变，产生严重的混叠失真（Aliasing Error）。无粘方程缺少耗散机制，高频能量无法排出，最终反噬整个数值系统。这直接催生了 Step 4：我们必须引入物理粘性扩散项来拯救求解器！
