◆ 本章定位与承前启后 · 破解网格上的“宇宙速度极限”

承接上章：在 Step 1 和 Step 2 中，我们亲眼见证了只要步长稍微迈得大了一点，数值解就会在几十步内彻底崩溃成 NaN。在工程中，这种现象被称为数值不稳定性（Numerical Instability）。

本章理论母题：数值偏微分方程领域最神圣的法则——CFL 稳定性条件（Courant-Friedrichs-Lewy Condition）：

$$\sigma = \frac{c \Delta t}{\Delta x} \le \sigma_{\max} = 1.0$$

它并不是某种凭空捏造的经验规则，而是深刻根植于因果律与特征线拓扑的几何公理。本章将从物理依赖域与数值依赖域的第一性原理出发，彻底攻克这一数值模拟的生死判据！

✦ 本章核心交付战果 ① 深刻理解物理依赖域（Analytical Domain of Dependence）与数值依赖域的几何覆盖公理；
② 掌握动态自适应时间步长（Adaptive Time Stepping）算法的工业级编写规范；
③ 亲手复现 $\sigma = 1.00$（稳定平移）与 $\sigma = 1.05$（指数级爆炸）的分岔相变。

1 · 第一性原理：特征线锥与依赖域几何公理

双曲型偏微分方程的信息传播是有限速的。设波速为 $c$。要计算时空点 $(x_i, t^{n+1})$ 处的真实物理场值，根据特征线理论，其值完全由其过往特征线交于 $t^n$ 时刻的点 $x_{\text{past}} = x_i - c\Delta t$ 唯一决定。这个点 $x_{\text{past}}$ 就是点 $(x_i, t^{n+1})$ 的物理依赖域（Analytical Domain of Dependence）。

与此同时，我们在计算机网格上使用一阶迎风格式：

$$u_i^{n+1} = (1 - \sigma) u_i^n + \sigma u_{i-1}^n$$

计算机在计算 $u_i^{n+1}$ 时，仅仅读取了格点 $x_{i-1}$ 与 $x_i$ 的数值。区间 $[x_{i-1}, x_i]$ 就是数值格式的数值依赖域（Numerical Domain of Dependence）。

◆ CFL 定理（1928 年，Courant, Friedrichs, Lewy） 一个显式有限差分格式能够收敛的必要条件是：数值依赖域必须完全包含物理依赖域！
几何判定极度直观：真实物理信息发源点 $x_i - c\Delta t$ 必须落在数值采样区间 $[x_{i-1}, x_i]$ 内部！ $$x_{i-1} \le x_i - c\Delta t \le x_i \iff c\Delta t \le \Delta x \iff \sigma = \frac{c\Delta t}{\Delta x} \le 1.0$$ 如果 $\sigma > 1.0$，物理信息点已经飞奔到了数值格式采样的网格格子外面！计算机在计算未来时，连产生结果的真实物理起源点看都没看过一眼，解怎么可能不发散？

2 · 工业级自适应安全步长实现

import numpy as np

def compute_adaptive_dt(dx, max_velocity, target_cfl=0.8):
    """
    工业级动态 CFL 保护步长计算器
    :param dx: 空间网格间距 [m]
    :param max_velocity: 流场当前最大特征流速 max|u| [m/s]
    :param target_cfl: 安全 Courant 裕度 (推荐 0.7~0.8)
    :return: 保证绝对安全的时间步长 dt
    """
    assert max_velocity > 1e-12, "流速接近绝对零，步长无需更新"
    dt = target_cfl * dx / max_velocity
    return dt

# 示范：当流场因非线性陡化导致峰值从 1.0 飙升到 2.5 时
dx = 0.05
dt_safe = compute_adaptive_dt(dx, max_velocity=2.5, target_cfl=0.8)
print(f"动态自适应安全时步: dt = {dt_safe:.5f} 秒")

4.2 极端参数极限三问（Extreme Limits）

  • 极限一（$\Delta t \to 0$ 时）：Courant 数 $\sigma \to 0$。算法极度安全绝不失稳，但计算推进所需总步数趋于无穷大，且每一步截断误差累加，人工数值粘性耗散达到顶峰。
  • 极限二（$\sigma = 1.0$ 临界时）：数值依赖域与物理特征线发生绝美几何重合。一阶迎风格式的人工粘性项 $\nu_{\text{num}} = \frac{c\Delta x}{2}(1 - \sigma)$ 奇迹般恰好等于 0，数值解退化为无任何耗散损耗的机器精度完美纯平移！
  • 极限三（量纲与现实反例）：物理量纲分析：$[c\Delta t] = [L]$ 为单个时步流体位移，$[\Delta x] = [L]$ 为格点间距，比值 $\sigma$ 是绝对无量纲标量纯数。现实世界中物理因果律由光锥严格锁定，任何数值算法试图跨越因果锥采样，必然遭到自然法则的数学惩罚。

4.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：很多初学者听闻隐式时间推进格式（如 Implicit Backward Euler）具有“无条件稳定性”，便认为在隐式算法中可以随意取 $\Delta t = 1000$ 秒进行计算，这种理解错在哪里？

【真实底层】：“无条件稳定”仅仅代表数值解的振幅不会无节制爆炸发散（矩阵谱半径 $\le 1$），绝对不代表数值解是精确可信的！过大的时间步长会产生极其巨大的时间截断误差 $O(\Delta t)$，将所有高频瞬态湍流微涡物理细节瞬间全部抹杀平滑。在物理瞬态流场模拟中，即便使用隐式格式，工程上也必须受限于 CFL 精度考量（通常限制 CFL 在 1~5 之间）。
