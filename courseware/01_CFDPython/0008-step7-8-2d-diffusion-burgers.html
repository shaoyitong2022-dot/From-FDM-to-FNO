本章物理母题：二维扩散方程与二维矢量耦合 Burgers 方程（Steps 7 & 8）：

$$\frac{\partial u}{\partial t} = \nu \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right) = \nu \nabla^2 u$$ $$\begin{cases} \frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} + v \frac{\partial u}{\partial y} = \nu \nabla^2 u \\[6pt] \frac{\partial v}{\partial t} + u \frac{\partial v}{\partial x} + v \frac{\partial v}{\partial y} = \nu \nabla^2 v \end{cases}$$

在二维空间中，微观分子热运动向所有方向一视同仁地扩散热量与动量。你将在此掌握计算物理中最神圣的算子——五点拉普拉斯差分模板（5-Point Laplacian Stencil），并直面流体力学最真实的复杂性：速度的横向分量 $u$ 与纵向分量 $v$ 不再孤立，而是通过对流项强力缠绕在一起！

1 · 数学物理基石：拉普拉斯算子的微观多向逃逸

连续介质中的扩散过程由傅里叶热传导定律或牛顿粘性切应力假定控制。热流矢量 $\mathbf{q} = -\kappa \nabla u$。根据能量守恒律，流入控制体的净通量等于系统内部能量的积累率：

$$\frac{\partial u}{\partial t} = -\nabla \cdot \mathbf{q} = \nabla \cdot (\nu \nabla u) = \nu \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right)$$

数学物理上，二阶导数 $\partial_{xx} u$ 代表函数在水平方向的曲率凹凸，$\partial_{yy} u$ 代表竖直方向的曲率凹凸。拉普拉斯算子 $\nabla^2 u$ 的物理本质极其朴素：它衡量了中心点处的数值与紧邻周围近邻平均值之间的相对落差！只要中心点比周围热，$\nabla^2 u < 0$，中心点温度就必然随时间降低；反之亦然。

2 · 慢动作离散化：十字型五点差分模板

对空间二阶导数在两坐标轴上分别采用二阶中心差分：

$$\frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1,j}^n - 2u_{i,j}^n + u_{i-1,j}^n}{\Delta x^2}, \quad \frac{\partial^2 u}{\partial y^2} \approx \frac{u_{i,j+1}^n - 2u_{i,j}^n + u_{i,j-1}^n}{\Delta y^2}$$

代入前向时间推进方程并整理，得到二维五点显式差分格式：

$$u_{i,j}^{n+1} = u_{i,j}^n + \nu \Delta t \left[ \frac{u_{i+1,j}^n - 2u_{i,j}^n + u_{i-1,j}^n}{\Delta x^2} + \frac{u_{i,j+1}^n - 2u_{i,j}^n + u_{i,j-1}^n}{\Delta y^2} \right]$$

正方形网格下极度优雅的“十字星权重”

当网格各向同性（$\Delta x = \Delta y = h$）时，令无量纲扩散参数 $r = \frac{\nu \Delta t}{h^2}$：

$$u_{i,j}^{n+1} = (1 - 4r) u_{i,j}^n + r \left( u_{i+1,j}^n + u_{i-1,j}^n + u_{i,j+1}^n + u_{i,j-1}^n \right)$$

这个极其漂亮的代数形式告诉我们：未来时刻中心点的值，是它自身旧值与上下左右四个邻居旧值的加权平均！

为满足极大值原理（防止高频自激振荡），中心权重必须大于等于零：

$$1 - 4r \ge 0 \implies r = \frac{\nu \Delta t}{h^2} \le \frac{1}{4} = 0.25$$

★ 警钟长鸣：一维扩散的稳定极限是 $r \le 0.5$；而在二维空间中，由于逃逸通道多了一倍，允许的时间步长被死死压制在 $r \le 0.25$ 之内！步长约束比对流更加严苛万分。

3 · 工业级最小自包含实现：2D 耦合 Burgers 求解

import numpy as np
import matplotlib.pyplot as plt

# 1. 空间与物理参数
nx, ny = 41, 41
Lx, Ly = 2.0, 2.0
dx = Lx / (nx - 1)
dy = Ly / (ny - 1)
nu = 0.01
nt = 120

# 满足 2D 扩散稳定条件: nu * dt / dx**2 <= 0.2
sigma_diff = 0.2
dt = sigma_diff * (dx**2 * dy**2) / (nu * (dx**2 + dy**2))

# 2. 构造 u 和 v 的初始场 (中央方形凸起)
u = np.ones((ny, nx))
v = np.ones((ny, nx))
u[int(0.5/dy):int(1.0/dy+1), int(0.5/dx):int(1.0/dx+1)] = 2.0
v[int(0.5/dy):int(1.0/dy+1), int(0.5/dx):int(1.0/dx+1)] = 2.0

# 3. 矢量耦合双场显式时间推进
for n in range(nt):
    un = u.copy()  # ★ 铁律：双场物理独立快照
    vn = v.copy()
    
    # 内部格点同时更新 u 和 v
    u[1:-1, 1:-1] = (un[1:-1, 1:-1] - 
                     dt/dx * un[1:-1, 1:-1] * (un[1:-1, 1:-1] - un[1:-1, :-2]) - 
                     dt/dy * vn[1:-1, 1:-1] * (un[1:-1, 1:-1] - un[:-2, 1:-1]) + 
                     nu*dt/dx**2 * (un[1:-1, 2:] - 2*un[1:-1, 1:-1] + un[1:-1, :-2]) + 
                     nu*dt/dy**2 * (un[2:, 1:-1] - 2*un[1:-1, 1:-1] + un[:-2, 1:-1]))
                     
    v[1:-1, 1:-1] = (vn[1:-1, 1:-1] - 
                     dt/dx * un[1:-1, 1:-1] * (vn[1:-1, 1:-1] - vn[1:-1, :-2]) - 
                     dt/dy * vn[1:-1, 1:-1] * (vn[1:-1, 1:-1] - vn[:-2, 1:-1]) + 
                     nu*dt/dx**2 * (vn[1:-1, 2:] - 2*vn[1:-1, 1:-1] + vn[1:-1, :-2]) + 
                     nu*dt/dy**2 * (vn[2:, 1:-1] - 2*vn[1:-1, 1:-1] + vn[:-2, 1:-1]))
                     
    # 四周固定狄利克雷边界
    u[0, :] = 1.0; u[-1, :] = 1.0; u[:, 0] = 1.0; u[:, -1] = 1.0
    v[0, :] = 1.0; v[-1, :] = 1.0; v[:, 0] = 1.0; v[:, -1] = 1.0

print(f"2D Burgers solved. Max U: {np.max(u):.4f}, Max V: {np.max(v):.4f}")
参数 / 语法物理数学含义典型值敏感性分析与工程防错

nu*dt/dx**2 <= 0.25二维扩散稳定性条件0.2分母包含网格平方 $\Delta x^2$，细网格下显式步长极度微小，计算开销巨大。
u[2:, 1:-1]沿 $Y$ 轴向上邻居 $(i, j+1)$上邻居切片五点中心差分的上方端点，与下方端点 u[:-2, 1:-1] 严格对称。

1. 无量纲参数：$r = \nu \Delta t / h^2 = 1.0 \times 0.2 / 1.0^2 = 0.2$；

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

在求解耦合二维 Burgers 方程时，一位工程师为了节省内存，省略了物理快照拷贝：

# 错误代码：耦合场时间层未隔离
for n in range(nt):
    # 省略了 un = u.copy(); vn = v.copy()
    u[1:-1, 1:-1] = u[1:-1, 1:-1] - dt/dx * u[1:-1, 1:-1] * ... # 原位覆盖更新 u
    # 计算 v 时直接使用了刚刚被覆盖更新的 u 场！
    v[1:-1, 1:-1] = v[1:-1, 1:-1] - dt/dx * u[1:-1, 1:-1] * (v[1:-1, 1:-1] - v[1:-1, :-2]) - ...

【排错审问任务】：指出为什么这种写法虽然不会抛出语法错误，但破坏了多场耦合系统的物理对称性？

▸ 查看故障根因分析与修复代码

【问题行】：原位覆盖导致更新 $v$ 时读取的是 $t^{n+1}$ 时刻的新 $u$，而读取的却是 $t^n$ 时刻的旧 $v$！

【失效机理】：动量方程要求在同一个时间步内，$u$ 场与 $v$ 场必须严格基于同一时刻的历史快照同步推进（时间同步因果律）。如果提前把更新后的 $u^{n+1}$ 喂给 $v$ 方程，就相当于 $u$ 场的时间跑在了 $v$ 场的前面，人为破坏了流场的涡量反对称性，在流场内部自发凭空激发出伪物理旋涡和虚假剪切力！

【修复代码】：

un = u.copy()
vn = v.copy()

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当粘性 $\nu \to 0$ 时，扩散耗散项彻底消失，二维 Burgers 方程退化为无粘非线性欧拉系统，流场会在交界处自发产生强烈的剪切失稳断层。
  • 极限二（趋近无穷大时）：当 $\nu \to \infty$ 时，局部热量瞬时各向同性均质化，全域所有初始凸起在 $t > 0$ 的第一个瞬间就被无差别拉平成常数基底。
  • 极限三（物理介质各向异性）：真实的拉普拉斯算子 $\nabla^2$ 仅适用于均质各向同性介质。若在页岩沉积层或碳纤维复合材料中，横向导热系数可能纵向大数百倍，此时扩散项必须由标量 $\nu$ 升级为非对角二阶扩散张量 $\nabla \cdot (\mathbf{K} \nabla u)$。

◆ 物理剧情大转折：流体宇宙中那个神秘的“监工”——压力！

到目前为止，我们推导的所有动力学方程（对流、扩散、Burgers）都有一个共同特点：时间前向显式推进——已知当前时刻 $t^n$，直接代入公式就能算出下一时刻 $t^{n+1}$。

但是，真实不可压缩流体（如水）还有一个不可违抗的铁律：体积不可压缩（散度必须为零：$\nabla \cdot \mathbf{u} = 0$）！为了强制满足这个约束，宇宙必须派遣一个无所不在的监工——压力场 $p(x,y)$！而压力场并不服从时间前向推进，它在空间中服从全域瞬态平衡的椭圆型方程（Laplace 与 Poisson 方程）！
