1 · 数学物理基石：不可压缩的深渊与 Helmholtz-Hodge 分解

1.1 压力的真正身份：无所不在的隐形监工

在可压缩空气动力学中，气体有状态方程 $p = \rho R T$，压力直接由密度和温度代数给出。但在不可压缩水动力学中，密度 $\rho = \text{const}$，连续性方程蜕变为了一个严格的几何运动学约束：

$$\nabla \cdot \mathbf{u} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} = 0$$

这意味着：在任意时刻、流场中任意一个无限小微团，流入的体积必须不多不少严格等于流出的体积！

那么压力 $p$ 究竟是什么？在数学上，压力根本不是热力学状态量，而是为了强行把速度场束缚在无散度约束流形上所必须引入的拉格朗日乘子（Lagrange Multiplier）！哪里试图汇聚变密，哪里就瞬间爆发出无限高的压力梯度将流体狠狠推开。

1.2 Helmholtz-Hodge 分解定理：投影法的数学灵魂

1968 年，Alexandre Chorin 基于伟大的矢量微积分分解定理构建了流体力学投影法：

◆ Helmholtz-Hodge 分解定理 任意平滑矢量场 $\mathbf{u}^*$，都可以唯一正交分解为一个严格无散度的螺线矢量场（Soleneidal Field）$\mathbf{u}^{n+1}$ 与一个纯标量场的无旋梯度（Gradient of a Scalar Potential）$\nabla \phi$ 之和： $$\mathbf{u}^* = \mathbf{u}^{n+1} + \nabla \phi$$

Chorin 的破局思路极其绝妙：

  1. 预测步（扔掉压力）：先暂时假装压力不存在，只由对流项与粘性扩散项前向推进，算出一个临时带散度的速度预测场 $\mathbf{u}^*$；
  2. 泊松求解步：对分解式两端取散度：$\nabla \cdot \mathbf{u}^* = \nabla \cdot \mathbf{u}^{n+1} + \nabla^2 \phi$。强制令最终物理速度无散度 $\nabla \cdot \mathbf{u}^{n+1} = 0$，立即导出压力泊松方程： $$\nabla^2 p = \frac{\rho}{\Delta t} \nabla \cdot \mathbf{u}^*$$
  3. 正交投影修正步：求解出压力场 $p$ 后，用其梯度将预测速度投影回物理流形： $$\mathbf{u}^{n+1} = \mathbf{u}^* - \frac{\Delta t}{\rho} \nabla p$$

2 · 慢动作离散化：压力泊松源项与边界条件

2.1 压力泊松方程右端项的连续展开

为了在同位网格上获得最佳鲁棒性，将动量对流散度展开代入泊松右端项，得到经典 Barba/CFD 展开形式：

$$\nabla^2 p = \rho \left[ \frac{1}{\Delta t} \left( \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} \right) - \left( \frac{\partial u}{\partial x} \right)^2 - 2 \frac{\partial u}{\partial y} \frac{\partial v}{\partial x} - \left( \frac{\partial v}{\partial y} \right)^2 \right]$$

第一项 $\frac{1}{\Delta t} \nabla \cdot \mathbf{u}^*$ 具有极强烈的工程现实意义——它是数值惩罚阻尼项，专门用来在每个时步动态消除由于离散截断误差引发的微小散度漂移；后续三项则是流体惯性剪切张量所产生的真实物理动态压力源。

2.2 顶盖驱动空腔（Lid-driven Cavity）的物理边界条件

计算域为一个 $1\text{m} \times 1\text{m}$ 的封闭正方形方腔：

  • 顶盖边界 ($y=1$)：以恒定速度沿水平向右拖拽流体：$u(x, 1) = 1.0, v(x, 1) = 0$；
  • 底边与侧壁 ($y=0, x=0, x=1$)：固定无滑移壁面（No-slip Wall）：$u = 0, v = 0$；
  • 压力边界条件：壁面处速度为常数，法向加速度为 0，由动量方程在边界处法向投影可知法向压力梯度必须归零（齐次诺伊曼边界条件）： $$\left. \frac{\partial p}{\partial y} \right|_{\text{top, bottom}} = 0, \quad \left. \frac{\partial p}{\partial x} \right|_{\text{left, right}} = 0$$

3 · 工业级最小自包含实现：顶盖驱动空腔求解器

import numpy as np
import matplotlib.pyplot as plt

# 1. 空间与流体参数配置
nx, ny = 41, 41
Lx, Ly = 2.0, 2.0
dx = Lx / (nx - 1)
dy = Ly / (ny - 1)
rho = 1.0
nu = 0.1      # 雷诺数 Re = U * L / nu = 1.0 * 2.0 / 0.1 = 20
dt = 0.001
nt = 500
nit = 50      # 压力泊松内迭代松弛步数

u = np.zeros((ny, nx))
v = np.zeros((ny, nx))
p = np.zeros((ny, nx))
b = np.zeros((ny, nx))

# 2. 时间步进大循环
for n in range(nt):
    un = u.copy()
    vn = v.copy()
    
    # 2.1 构造压力泊松方程源项 b(x,y)
    b[1:-1, 1:-1] = rho * (1 / dt * ((un[1:-1, 2:] - un[1:-1, :-2]) / (2 * dx) + 
                                     (vn[2:, 1:-1] - vn[:-2, 1:-1]) / (2 * dy)) -
                           ((un[1:-1, 2:] - un[1:-1, :-2]) / (2 * dx))**2 - 
                           2 * ((un[2:, 1:-1] - un[:-2, 1:-1]) / (2 * dy) * 
                                (vn[1:-1, 2:] - vn[1:-1, :-2]) / (2 * dx)) - 
                           ((vn[2:, 1:-1] - vn[:-2, 1:-1]) / (2 * dy))**2)
                           
    # 2.2 压力泊松方程内迭代松弛
    for q in range(nit):
        pn = p.copy()
        p[1:-1, 1:-1] = (((pn[1:-1, 2:] + pn[1:-1, :-2]) * dy**2 + 
                          (pn[2:, 1:-1] + pn[:-2, 1:-1]) * dx**2 - 
                          b[1:-1, 1:-1] * dx**2 * dy**2) / (2 * (dx**2 + dy**2)))
        # 齐次诺伊曼压力边界: dp/dx = 0, dp/dy = 0
        p[:, -1] = p[:, -2]  # 右壁
        p[0, :] = p[1, :]    # 底壁
        p[:, 0] = p[:, 1]    # 左壁
        p[-1, :] = 0.0       # 顶盖处锚定参考零势点
        
    # 2.3 动量推进与压力正交投影修正
    u[1:-1, 1:-1] = (un[1:-1, 1:-1] - 
                     un[1:-1, 1:-1] * dt / dx * (un[1:-1, 1:-1] - un[1:-1, :-2]) - 
                     vn[1:-1, 1:-1] * dt / dy * (un[1:-1, 1:-1] - un[:-2, 1:-1]) - 
                     dt / (2 * rho * dx) * (p[1:-1, 2:] - p[1:-1, :-2]) + 
                     nu * dt / dx**2 * (un[1:-1, 2:] - 2 * un[1:-1, 1:-1] + un[1:-1, :-2]) + 
                     nu * dt / dy**2 * (un[2:, 1:-1] - 2 * un[1:-1, 1:-1] + un[:-2, 1:-1]))
                     
    v[1:-1, 1:-1] = (vn[1:-1, 1:-1] - 
                     un[1:-1, 1:-1] * dt / dx * (vn[1:-1, 1:-1] - vn[1:-1, :-2]) - 
                     vn[1:-1, 1:-1] * dt / dy * (vn[1:-1, 1:-1] - vn[:-2, 1:-1]) - 
                     dt / (2 * rho * dy) * (p[2:, 1:-1] - p[:-2, 1:-1]) + 
                     nu * dt / dx**2 * (vn[1:-1, 2:] - 2 * vn[1:-1, 1:-1] + vn[1:-1, :-2]) + 
                     nu * dt / dy**2 * (vn[2:, 1:-1] - 2 * vn[1:-1, 1:-1] + vn[:-2, 1:-1]))
                     
    # 2.4 物理壁面无滑移边界条件
    u[0, :] = 0.0; u[:, 0] = 0.0; u[:, -1] = 0.0
    u[-1, :] = 1.0  # ★ 顶盖以 U=1.0 向右拖拽
    v[0, :] = 0.0; v[-1, :] = 0.0; v[:, 0] = 0.0; v[:, -1] = 0.0

print(f"Cavity flow completed. Center vortex formed! Max U: {np.max(u):.4f}")

4.3 单步离散手算推演（Trace the Path）

◆ 纸笔手算心智模型对齐

【初始局部离散状态】：在某网格点 $(i,j)$，预测速度场为 $u^* = 2.0, v^* = 1.0$。求解压力泊松方程后，探测到该点周围的压力场分布为：
右邻居 $p_{i+1,j} = 10.0$，左邻居 $p_{i-1,j} = 2.0$；上邻居与下邻居压力相等。
设密度 $\rho = 1.0$，网格步长 $\Delta x = 0.5$，时间步长 $\Delta t = 0.1$。

【手动推演任务】：求经过压力投影修正后，该点最终的水平物理速度 $u_{i,j}^{n+1}$。

▸ 查看单步推演标准数值解答
1. 计算水平压力梯度：$\frac{\partial p}{\partial x} = \frac{p_{i+1,j} - p_{i-1,j}}{2\Delta x} = \frac{10.0 - 2.0}{2\times 0.5} = 8.0\text{ Pa/m}$；
2. 压力阻力修正：$-\frac{\Delta t}{\rho} \frac{\partial p}{\partial x} = -\frac{0.1}{1.0} \times 8.0 = -0.8$；
3. 最终投影速度：$u_{i,j}^{n+1} = u^* - 0.8 = 2.0 - 0.8 = 1.2$。
物理直觉验证：右侧压力显著高于左侧（逆压梯度），流体在向前运动时遭遇高压阻挡，速度从原本预测的 2.0 被硬生生削减为 1.2！这就是压力强行重塑流动轨迹的真实过程。

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

在同位笛卡尔网格（Collocated Grid）上，一位同学在更新速度时发现流场出现严重的“奇偶黑白相间的棋盘格高频压力波”，但速度场似乎毫无反应，程序运行一段时间后突然发散崩溃：

【排错审问任务】：揭示同位网格上中心差分跨点的“棋盘格解耦”（Checkerboard Decoupling）致命缺陷，指出为什么工业 CFD 必须采用交错网格（Staggered MAC Grid）或增加内迭代阻尼？

▸ 查看故障根因分析与修复代码

【失效机理】：跨点差分 $(p_{i+1} - p_{i-1})/(2\Delta x)$ 恰好跳过了中心节点 $i$！如果压力场存在奇数点全为 $+100$、偶数点全为 $-100$ 的剧烈黑白棋盘格寄生振荡，代入差分公式后相减居然全部等于 0！动量方程完全感知不到眼前剧烈的压力振荡，使得压力误差无拘无束地恶性滋生，最终彻底摧毁解的真实性。

【工业根治方案】：工业级 Navier-Stokes 求解器（如 Harlow & Welch 的 MAC 网格）将压力定义在网格中心，将速度 $u$ 定义在垂直交界面，将速度 $v$ 定义在水平交界面（网格交错半个步长），差分直接作用于相邻格点，在拓扑上彻底物理歼灭棋盘格假象。

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当雷诺数 $Re \to 0$（极低速或极高粘度，如沥青或微米细菌在水中游动）时，惯性非线性项完全可以忽略不计，Navier-Stokes 退化为严格对称且时间可逆的稳态 Stokes 蠕动流（Purcell 扇贝定理）。
  • 极限二（趋近无穷大时）：当雷诺数 $Re \to \infty$ 时，分子粘性耗散层厚度趋于零，边界层发生剧烈分离脱落，流场演化为具有无限尺度级联传递的三维不可压缩湍流（Richardson 能量级联）。
  • 极限三（物理声速失效极限）：自然界没有绝对不可压缩的流体。当流速接近或超过介质声速的 30%（马赫数 $Ma > 0.3$）时，声波携带的压缩波形无法瞬态平滑全域，连续性方程的不可压缩假设彻底破灭，必须回归可压缩气体动力学方程组。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么很多人在写 Cavity Flow 时，把顶壁两个角隅点 $(0, ny-1)$ 和 $(nx-1, ny-1)$ 的水平速度既想设为 1.0 又想设为 0.0，最后引发程序报错？

【真实底层】：这是经典的奇异角隅点（Singular Corner Paradox）！顶盖要求滑动速度为 1.0，而侧壁要求固定静止速度为 0.0，两面墙壁在直角顶点产生拓扑冲突，该点的数学剪切应力理论上趋向无穷大！在有限差分实现中，必须做出明确选择（通常将角隅点归属于静止壁面），并认识到这是离散几何边界导致的局部奇点，切莫与算法失稳混为一谈。
