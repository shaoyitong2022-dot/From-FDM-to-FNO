本章物理母题：热力学与流体力学的耗散基石——一维扩散方程（Heat / Diffusion Equation）：

$$\frac{\partial u}{\partial t} = \nu \frac{\partial^2 u}{\partial x^2}$$

与对流方程的“单向刚体平移”截然不同，扩散方程是典型的抛物型（Parabolic）偏微分方程。它描述了热量、流体粘性动量由高浓度向低浓度的全方位均质化扩散。本章我们将推导二阶中心差分算子，并直面比对流 CFL 严苛十倍的抛物型刚性步长约束 $\Delta t \propto \Delta x^2$！

✦ 本章核心交付战果 ① 严格掌握二阶导数三点中心差分模板（$1, -2, 1$）的泰勒推导；
② 揭示抛物型扩散数 $r = \nu \frac{\Delta t}{\Delta x^2} \le 0.5$ 的刚性稳定性边界；
③ 实测高频 Nyquist 棋盘格模式（Checkerboard Mode）在 $r > 0.5$ 下的瞬间爆发现象。

1 · 物理机制：微观随机碰撞与宏观不可逆平滑

扩散方程描述的是微观布朗随机游走在宏观连续介质中的涌现表现。若在空间某处存在一个局域凸起波峰，微观分子无规则碰撞会导致能量向周围四散逃逸。数学上：

  • 在波峰处：曲线向下凹陷，二阶导数 $\partial_{xx} u < 0$，因此 $\partial_t u = \nu \partial_{xx} u < 0$，峰顶被迫下降削平；
  • 在波谷处：曲线向上凹陷，二阶导数 $\partial_{xx} u > 0$，因此 $\partial_t u > 0$，谷底被推高填平！

扩散算子像一把无比灵巧的砂纸，时刻打磨着全场的一切高阶毛刺。根据热力学第二定律，这种平滑过程具有严格的时间单向箭头（不可逆性），任何尖锐的信息都在扩散中被永久抹杀降解。

2 · 慢动作离散化：二阶中心差分与 FTCS 格式

对空间二阶导数，在点 $x_i$ 处分别向右（$+dx$）和向左（$-dx$）做四阶泰勒级数展开：

$$u_{i+1} = u_i + \Delta x \partial_x u_i + \frac{\Delta x^2}{2} \partial_{xx} u_i + \frac{\Delta x^3}{6} \partial_{xxx} u_i + O(\Delta x^4)$$ $$u_{i-1} = u_i - \Delta x \partial_x u_i + \frac{\Delta x^2}{2} \partial_{xx} u_i - \frac{\Delta x^3}{6} \partial_{xxx} u_i + O(\Delta x^4)$$

将两式直接相加，奇数阶奇次导数奇迹般完全相消抵消！得到高精度的二阶中心差分格式（Central Difference）：

$$\frac{\partial^2 u}{\partial x^2} \approx \frac{u_{i+1}^n - 2u_i^n + u_{i-1}^n}{\Delta x^2} + O(\Delta x^2)$$

结合时间前向显式欧拉差分，便得到了求解扩散方程的经典 FTCS 格式（Forward-Time Central-Space）：

$$u_i^{n+1} = u_i^n + \nu \frac{\Delta t}{\Delta x^2} (u_{i+1}^n - 2u_i^n + u_{i-1}^n)$$

定义无量纲扩散数（Diffusion Number）：

$$r \equiv \nu \frac{\Delta t}{\Delta x^2}$$

代入重写为加权平均形态：

$$u_i^{n+1} = (1 - 2r) u_i^n + r (u_{i+1}^n + u_{i-1}^n)$$
◆ 深度物理透视｜极值原理与稳定性边界 $r \le 0.5$ 观察上式：新时刻的值 $u_i^{n+1}$ 是自身旧值 $u_i^n$ 与左右邻居旧值的线性组合。
为了保证新解不发生非物理振荡（满足热力学最大值原理），自身旧值的权重系数绝不能为负数！ $$1 - 2r \ge 0 \implies r = \nu \frac{\Delta t}{\Delta x^2} \le \frac{1}{2} = 0.5$$ 若 $r > 0.5$，中心点反而成为负反馈放大器，数值解将瞬间暴发高频黑白相间的剧烈锯齿炸飞！

3 · 工业级最小自包含实现

import numpy as np
import matplotlib.pyplot as plt

def solve_diffusion(nx=41, nu=0.3, dt=0.002, nt=20):
    dx = 2.0 / (nx - 1)
    x = np.linspace(0, 2.0, nx)
    r = nu * dt / (dx**2)
    assert r <= 0.5, f"扩散数超标! r={r:.3f} > 0.5"
    
    # 初始方帽
    u = np.ones(nx)
    u[int(0.5 / dx) : int(1.0 / dx + 1)] = 2.0
    
    for n in range(nt):
        un = u.copy()
        # 二阶中心差分向量化切片
        u[1:-1] = un[1:-1] + r * (un[2:] - 2 * un[1:-1] + un[:-2])
        # 狄利克雷边界保持为 1.0
        u[0] = 1.0; u[-1] = 1.0
        
    return x, u, r

if __name__ == '__main__':
    x, u, r = solve_diffusion()
    plt.plot(x, u, 'g-o', label=f'FTCS Diffusion (r={r:.3f})')
    plt.title('Step 3: 1D Diffusion')
    plt.xlabel('x [m]'); plt.ylabel('u [m/s]')
    plt.grid(True); plt.legend()
    plt.show()

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

某新手在编写扩散代码时误漏写了分母的平方，当网格从 $nx=41$ 加密至 $nx=201$ 时，算例瞬间发生数值爆炸：

# 错误写成了 dx 而非 dx**2
u[1:-1] = un[1:-1] + nu * dt / dx * (un[2:] - 2*un[1:-1] + un[:-2])

【排错审问任务】：指出该代码的量纲错误与数值后果。

▸ 查看故障根因分析与修复代码

【问题行】：nu * dt / dx 缺少平方。

【失效机理】：二阶导数分母量纲为 $[L]^2$。当网格加密到 $dx = 0.01$ 时，分母相比正确值被放大了 100 倍（因为少除了一个 0.01），实际生效系数超标百倍，引发极其剧烈的数值发散。

【修复代码】：

u[1:-1] = un[1:-1] + nu * dt / (dx**2) * (un[2:] - 2*un[1:-1] + un[:-2])

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（粘性/扩散系数 $ u \to 0$ 时）：扩散项彻底消失，方程退化为时间冻结状态，局部热量和动量永远锁死在初始尖锐形态。
  • 极限二（粘性/扩散系数 $ u \to \infty$ 时）：扩散速度无穷大，全域瞬间达到绝对均温稳态，抛物型方程蜕变为椭圆型拉普拉斯代数方程。
  • 极限三（量纲与现实反例）：物理量纲分析：$[ u] = [L]^2/[T]$，因此与时间步长的结合必然形成无量纲数 $r = u \Delta t / \Delta x^2$。现实世界中由于时间步长必须满足 $\Delta t \propto \Delta x^2$，网格每加密 10 倍，显式步长必须缩小 100 倍！这构成了显式求解扩散方程极其痛苦的刚性算力枷锁（Stiff Problem）。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：显式扩散格式受制于极其苛刻的 $\Delta t \propto \Delta x^2$，在大规模工程 CFD 中，人们是如何攻克这个算力黑洞的？

【真实底层】：工业求解器（如 OpenFOAM 或 ANSYS Fluent）在处理粘性扩散项时，普遍抛弃显式欧拉，转向隐式格式（如 Crank-Nicolson 或隐式欧拉 Backward Euler）！通过求解一个对称正定的稀疏三对角线性方程组，换取无条件绝对稳定（Unconditionally Stable），使时间步长彻底摆脱 $\Delta x^2$ 的死咒，仅需根据物理流动时间尺度设定。
