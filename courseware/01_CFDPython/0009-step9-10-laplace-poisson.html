本章物理母题：数学物理方程的第三大巅峰家族——椭圆型偏微分方程（Laplace 与 Poisson 方程，Steps 9 & 10）：

$$\nabla^2 p = \frac{\partial^2 p}{\partial x^2} + \frac{\partial^2 p}{\partial y^2} = 0 \quad (\text{Laplace})$$ $$\nabla^2 p = \frac{\partial^2 p}{\partial x^2} + \frac{\partial^2 p}{\partial y^2} = b(x,y) \quad (\text{Poisson})$$

注意！方程里根本没有时间导数 $\partial_t$！它描述的是一个处于绝对稳态平衡的物理系统（静电场、引力势场、不可压缩流体中的压力平衡场）。任何边界上的轻微扰动，都会在瞬间被全宇宙感知并重新排布平衡。你将在此掌握五点离散线性方程组的迭代松弛求解法（Jacobi vs Gauss-Seidel），并目睹网格加密时松弛收敛步数暴增 4 倍的残酷现实！

1 · 数学与物理基石：椭圆型方程的全域平衡与极值原理

1.1 强极值原理与均值定理

在没有内部源项的调和域内（Laplace 方程 $\nabla^2 p = 0$），解具有极度优美的数学性质——高斯均值定理（Mean Value Theorem）：域内任意一点的值，严格等于以该点为圆心的任意同心圆周上的平均值！

由此直接导出强极值原理（Strong Maximum Principle）：调和函数的最大值和最小值必然且只能出现在计算域的物理边界上，内部绝不可能自发孕育出孤立的局域极大值或极小值峰值！一旦边界确定，全域内部形态被唯一且光滑地彻底冻结。

1.2 泊松方程：源项强迫产生的曲率势阱

当存在质量源、电荷源或动量散度漂移时，拉普拉斯算子被源项打破：$\nabla^2 p = b(x,y)$。源项 $b > 0$ 的区域相当于在平整弹性膜上向下施加重力压迫，产生势能低谷；源项 $b < 0$ 的区域则向上顶起峰值。无论源项多么复杂，只要四周边框固定，整张膜的平衡状态在数学上是唯一确定的。

2 · 慢动作离散化：五点星型模板与迭代松弛法

采用空间二阶中心差分，离散泊松方程写作：

$$\frac{p_{i+1,j} - 2p_{i,j} + p_{i-1,j}}{\Delta x^2} + \frac{p_{i,j+1} - 2p_{i,j} + p_{i,j-1}}{\Delta y^2} = b_{i,j}$$

在正方形网格（$\Delta x = \Delta y$）下，将中心点 $p_{i,j}$ 单独分离到等号左侧：

$$p_{i,j} = \frac{1}{4} \left( p_{i+1,j} + p_{i-1,j} + p_{i,j+1} + p_{i,j-1} - b_{i,j} \Delta x^2 \right)$$

这不再是一个时间推进公式，而是一个拥有 $(n_x - 2) \times (n_y - 2)$ 个相互缠绕未知数的巨大稀疏线性代数方程组 $A \mathbf{p} = \mathbf{b}$！

松弛迭代的智慧：Jacobi 与 Gauss-Seidel

直接求解大型矩阵求逆开销巨大（$O(N^3)$）。我们引入迭代计数器 $k$：

  • Jacobi 迭代：严格基于第 $k$ 次迭代的全局旧值计算所有新值： $$p_{i,j}^{(k+1)} = \frac{1}{4} \left( p_{i+1,j}^{(k)} + p_{i-1,j}^{(k)} + p_{i,j+1}^{(k)} + p_{i,j-1}^{(k)} - b_{i,j} \Delta x^2 \right)$$
  • Gauss-Seidel 迭代：随算随用！由于计算机按顺序遍历网格，在计算 $(i,j)$ 时，左邻居 $(i-1, j)$ 和下邻居 $(i, j-1)$ 已经具有新鲜出炉的第 $k+1$ 次迭代值，直接代入： $$p_{i,j}^{(k+1)} = \frac{1}{4} \left( p_{i+1,j}^{(k)} + p_{i-1,j}^{(k+1)} + p_{i,j+1}^{(k)} + p_{i,j-1}^{(k+1)} - b_{i,j} \Delta x^2 \right)$$

代数分析证明，Gauss-Seidel 迭代矩阵的谱半径恰好是 Jacobi 谱半径的平方（$\rho_{GS} = \rho_J^2$），这意味着在相同内存开销下，Gauss-Seidel 的误差衰减速度整整快了一倍！

3 · 工业级最小自包含实现

import numpy as np
import matplotlib.pyplot as plt

# 1. 空间与网格配置
nx, ny = 41, 41
Lx, Ly = 2.0, 1.0
dx = Lx / (nx - 1)
dy = Ly / (ny - 1)

# 2. 初始场与源项 b(x,y)
p = np.zeros((ny, nx))
b = np.zeros((ny, nx))
# 在两个特定对称位置设置正负点源
b[int(ny / 4), int(nx / 4)] = 100.0
b[int(3 * ny / 4), int(3 * nx / 4)] = -100.0

# 3. Gauss-Seidel / Jacobi 松弛迭代求解
tol = 1e-4
max_iter = 2000
diff = 1.0
iteration = 0

while diff > tol and iteration < max_iter:
    pn = p.copy()
    
    # 五点中心松弛切片更新
    p[1:-1, 1:-1] = (dy**2 * (pn[1:-1, 2:] + pn[1:-1, :-2]) + 
                     dx**2 * (pn[2:, 1:-1] + pn[:-2, 1:-1]) - 
                     b[1:-1, 1:-1] * dx**2 * dy**2) / (2 * (dx**2 + dy**2))
                     
    # 严格狄利克雷边界保持为 0
    p[0, :] = 0.0; p[-1, :] = 0.0; p[:, 0] = 0.0; p[:, -1] = 0.0
    
    # 计算无量纲相对 L2 范数残差
    diff = np.linalg.norm(p - pn) / (np.linalg.norm(pn) + 1e-12)
    iteration += 1

print(f"Poisson solved in {iteration} iterations. Relative L2 Residual: {diff:.4e}")
参数 / 语法物理数学含义典型值敏感性分析与工程防错
b[ny/4, nx/4] = 100.0点源脉冲激扰$\pm 100$正源产生局部下凹漏斗势阱，负源产生凸起峰值。
np.linalg.norm(p - pn) / norm(pn)相对 $L_2$ 范数变化率$< 10^{-4}$必须使用相对量除以旧值范数，规避网格加密引发的求和绝对量膨胀。
2 * (dx**2 + dy**2)各向异性归一化分母分母当 $dx \ne dy$ 时的通用严密分母；若误除以 4 会彻底破坏椭圆平衡。

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

一位初学者编写了如下松弛终止逻辑，发现在粗网格下能正常收敛，但一旦将网格加密到 $100 \times 100$ 时，程序就陷入无休止的死循环：

# 错误代码：绝对误差和终止条件
while True:
    pn = p.copy()
    p[1:-1, 1:-1] = ... # 松弛计算
    # 绝对值之和小于 1e-4
    if np.sum(np.abs(p - pn)) < 1e-4:
        break

【排错审问任务】：指出为什么网格越密，np.sum 越不可能小于固定阈值？给出工业级归一化修复方案。

▸ 查看故障根因分析与修复代码

【问题行】：if np.sum(np.abs(p - pn)) < 1e-4:

【失效机理】：np.sum 计算的是全网格所有误差的绝对代数和。当网格从 $20\times 20$（400 点）加密到 $100\times 100$（10000 点）时，参与求和的格点数暴增了 25 倍！哪怕每个格点的局域单点误差已经下降到 $10^{-7}$，一万个点累加起来依然大于 $10^{-4}$，导致程序永远无法满足跳出条件陷入假死。

【修复代码】：

if np.linalg.norm(p - pn) / np.linalg.norm(pn) < 1e-4:
    break

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当源项 $b(x,y) \to 0$ 时，泊松方程退化为拉普拉斯方程，全域内部绝无孤立极值点，解完全由边界形状全权掌控。
  • 极限二（信息传播速度极限）：在双曲型对流方程中，信息以有限波速 $c$ 传播；但在椭圆型方程中，数学上的信息传播速度是无穷大！只要边界上某一个点的电位微调 0.001 伏，全域无限远深处所有格点瞬间全盘重新洗牌响应。
  • 极限三（物理破缺与诺伊曼相容性条件）：若四周边框全部施加诺伊曼无流边界 $\partial p / \partial n = 0$，根据高斯散度定理，源项必须满足积分平衡 $\iint b(x,y) dx dy = 0$！若净源项不为零，系统在物理上等价于在一个封闭刚性罐子里不断注水，内部压力将无休止暴增至无穷大（代数方程无解）。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么明明泊松方程是描述稳态平衡的静态方程，我们在写代码时却非要在外面包上一层 while 循环甚至定义类似于时间步进的迭代？

【真实底层】：因为计算机无法直接肉眼看出庞大联立方程组的解！我们在数值上构建了一个虚拟时间动力系统（Pseudo-time System）：$\frac{\partial p}{\partial \tau} = \nabla^2 p - b$。我们让系统从随意猜测的初值开始，任由其在虚拟时间 $\tau$ 里耗散释放应力，当虚拟时间趋于无穷大（$\partial_\tau p \to 0$）时，系统残留下来的稳态解正是代数方程组的精确解！这是松弛算法最深沉的哲学设计。
