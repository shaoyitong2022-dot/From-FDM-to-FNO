1 · 数学物理基石：时空流形与全域连续求解

1.1 为什么将时间视为第四个空间维度？

在传统时间步进算法（如 Runge-Kutta 或有限差分显式推进）中，时间具有严格的单向因果链。如果我们在第 10 秒放置了一个传感器，传统算法必须先从第 0 秒一步不落地算到第 10 秒才能利用这个数据；如果第 10 秒的数据与初值有冲突，传统算法无法逆向修正初值。

而在全时空 PINN 中，时空坐标被统一表示为流形上的点：

$$\mathbf{X} = (x, t) \in \Omega \times [0, T]$$

时间 $t$ 没有任何特权，它只是输入张量的第二列！神经网络一次前向传播，同时覆盖过去、现在与未来的所有时空点。不仅支持全时空超大规模并行评估，更允许未来的传感器数据在计算图中顺畅反向传播，逆向纠偏初始状态！

1.2 激波附近的梯度饥饿（Gradient Starvation）

当粘性系数极小（如 $\nu = 0.01 / \pi$）时，初始平滑的正弦波 $u(x, 0) = -\sin(\pi x)$ 会在 $t \approx 0.5$ 附近陡化坍缩，形成极其尖锐、近乎垂直的跳跃前沿（激波）。

在全时空域内，激波过渡层占据的体积不到总时空体积的 1%。如果采用常规的均匀随机采样，99% 的配点都落在了平缓区。这些平缓区的残差很小，向优化器贡献了大量平庸的梯度；而激波剧烈跳跃处的极端残差被稀释淹没，导致网络在激波尖锐处优化停滞，波前被错误地磨平钝化。这催生了工业级 SciML 的核心前沿——自适应配点残差重采样（RAR, Residual-based Adaptive Refinement）！

2 · 慢动作剖析：全时空 Burgers 工业代码实现

import deepxde as dde
import numpy as np
import torch

# 1. 物理参数: 极小粘性产生强烈非线性激波
nu = 0.01 / np.pi

# 2. 声明时空圆柱体几何体 (GeometryXTime)
geom = dde.geometry.Interval(-1.0, 1.0)
timedomain = dde.geometry.TimeDomain(0.0, 0.99)
geomtime = dde.geometry.GeometryXTime(geom, timedomain)

# 3. 声明时空 Burgers 偏微分方程残差
def pde_burgers_spacetime(x, y):
    # x 包含两列: x[:, 0] 是空间 x，x[:, 1] 是时间 t
    # y 对应流速 u
    # 3.1 空间一阶导 u_x 与时间一阶导 u_t
    u_x = dde.grad.jacobian(y, x, i=0, j=0)
    u_t = dde.grad.jacobian(y, x, i=0, j=1)  # 注意时间是第 1 维！
    
    # 3.2 空间二阶纯导 u_xx
    u_xx = dde.grad.hessian(y, x, component=0, i=0, j=0)
    
    # 3.3 返回非线性 Burgers 残差
    return u_t + y * u_x - nu * u_xx

# 4. 边界与初始条件
# 空间两端狄利克雷边界 u(-1, t) = 0, u(1, t) = 0
bc = dde.icbc.DirichletBC(geomtime, lambda x: 0.0, lambda _, on_bnd: on_bnd)

# 初始时刻波形 u(x, 0) = -sin(pi * x)
def initial_condition(x):
    # 必须保持二维张量 (N, 1)，利用切片 x[:, 0:1]
    return -np.sin(np.pi * x[:, 0:1])

ic = dde.icbc.IC(geomtime, initial_condition, lambda _, on_initial: on_initial)

# 5. 数据装配与深层网络配置
data = dde.data.TimePDE(
    geomtime, pde_burgers_spacetime, [bc, ic],
    num_domain=2500,    # 时空域随机配点
    num_boundary=100,   # 空间边界配点
    num_initial=160     # 初始时刻配点
)

# 搭建 4 层 40 隐藏神经元 MLP
net = dde.nn.FNN([2] + [40] * 4 + [1], "tanh", "Glorot normal")
model = dde.Model(data, net)

# 6. 两阶段工业级优化: 先 Adam 预热，再 L-BFGS 精修
model.compile("adam", lr=1e-3)
model.train(iterations=2000)
# 切换至 L-BFGS 强力二阶微调，强行切出垂直激波刃面！
model.compile("L-BFGS")
losshistory, train_state = model.train()
API / 特性数学物理内涵工程关键细节
GeometryXTime张量积时空连续流形 $\Omega imes [0, T]$彻底砸碎离散步长与 CFL 时间红线束缚。
x[:, 0:1] 切片列切片防降维若误写为 x[:, 0] 会丢失维度引发广播灾难。

3.3 激波演化截面手算推演（Trace the Path）

◆ 激波形成时间心智模型对齐

【初值形态】：$u(x, 0) = -\sin(\pi x)$ 在 $x \in [-1, 1]$ 上。
在原点 $x=0$ 附近，泰勒展开为：$u(x, 0) pprox -\pi x$。斜率为负！波峰在左（$u>0$ 向右跑），波谷在右（$u<0$ 向左跑）。

【推演任务】：求无粘条件下特征线最先在原点相撞形成激波的临界时间 $t_{ ext{break}}$。

▸ 查看相撞时间推演解答
由特征线方法可知，波形破裂时间由初始最大负斜率的倒数决定：
$t_{ ext{break}} = - rac{1}{\min(\partial_x u_0)} = - rac{1}{-\pi} = rac{1}{\pi} pprox 0.318 ext{ s}$！
在 $t < 1/\pi$ 时波形平滑变陡；在 $t \ge 1/\pi$ 时激波正式诞生并持续耗散。PINN 必须在这个临界时间点精准切换曲率！

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

在编写初始条件函数时，一位同学为了简写切片，写成了如下代码，导致显存瞬间被吃满：

def ic_func(x):
    # 试图提取第一列 x
    return -np.sin(np.pi * x[:, 0])  # BUG! 返回形状为 (N,)

【排错审问任务】：指出为什么 x[:, 0] 会丢失列维度？如何利用 Python 切片切出标准两维张量？

▸ 查看故障根因分析与修复代码

【失效机理】：单下标切片 x[:, 0] 在 NumPy 中会执行降维操作，返回长度为 $N$ 的一维向量。当与输出张量 (N, 1) 做差时，PyTorch 广播机制会将两者相减扩展为 $N imes N$ 的万维矩阵！不仅显存瞬间激增，且计算出的均方误差完全失去物理意义。

【修复代码】：

def ic_func(x):
    return -np.sin(np.pi * x[:, 0:1])  # 必须使用 0:1 保持 (N, 1) 列维度

4.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当时间终点 $T o 0$ 时，时空圆柱体塌缩为一个极薄切片，退化为纯空间初值赋范拟合。
  • 极限二（粘性趋于 0 时）：当 $ u o 0$ 时，激波面坡度理论上趋于垂直，常规光滑神经网络遭遇严重的梯度爆炸，必须引入人工粘性或激波捕获正则项。
  • 极限三（时间不可逆性打破）：全时空求解将双曲动力系统在形式上“椭圆化”了。如果时间跨度拉得过长（如模拟上万秒），时间方向会丧失单向因果链的支配，导致深层网络陷入局部病态极小值；工业超长时序仍需结合时间分段推进（Time-marching PINN）。

4.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么很多人在算激波时，死命把配点数从 2000 点增加到 100 万点，结果不仅没有解决激波模糊，反而直接跑崩了显存？

【真实底层】：因为盲目均匀撒点是最低效的算力自杀！100 万个点里有 99 万个都浪费在根本不需要算力的平缓区域。解决激波模糊的唯一正确工程路径，是自适应残差重采样（RAR）——让算法动态监视全域残差，哪里残差大（激波锋面），就在哪里自动密集补刀撒点；哪里平缓，就稀疏采点！用最少的配点锁死最锋利的界面，这才是高级科学家的手笔。
