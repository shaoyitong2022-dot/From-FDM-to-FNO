2 · 慢动作剖析：引入 PointSetBC 的工业级完整实现

import deepxde as dde
import numpy as np

# 1. 物理系统参数与解析基准
m, mu, k = 1.0, 0.4, 4.0
gamma = mu / (2 * m)
omega = np.sqrt(k / m - gamma**2)
def exact_solution(t):
    return np.exp(-gamma * t) * np.cos(omega * t)

# 2. 几何时间域 [0, 5]
geom = dde.geometry.TimeDomain(0.0, 5.0)

# 3. 声明阻尼振子控制方程残差: m * y'' + mu * y' + k * y = 0
def pde_oscillator(t, y):
    y_t = dde.grad.jacobian(y, t, i=0, j=0)
    y_tt = dde.grad.hessian(y, t, i=0, j=0)
    return m * y_tt + mu * y_t + k * y

# 4. 模拟外部传感器采集到的 5 个稀疏测量点
t_sensor = np.array([[0.5], [1.2], [2.1], [3.3], [4.5]])
u_sensor = exact_solution(t_sensor)

# 5. 声明边界条件集合: 包含初始位移与实验传感器散点
def on_initial(t, on_initial_pt):
    return on_initial_pt

bc_ic = dde.icbc.DirichletBC(geom, lambda t: 1.0, on_initial)
bc_data = dde.icbc.PointSetBC(t_sensor, u_sensor)  # ★ 数据驱动注入

# 6. 数据装配与网络声明
data = dde.data.PDE(
    geom, pde_oscillator, [bc_ic, bc_data],
    num_domain=400,
    num_boundary=2,
    solution=exact_solution,
    num_test=200
)

net = dde.nn.FNN([1] + [32] * 3 + [1], "tanh", "Glorot uniform")
model = dde.Model(data, net)

# 7. 编译优化器: 注意 loss_weights 顺序对应 [PDE, BC_IC, BC_DATA]
# 必须给初值和传感器数据足够的惩罚权重，防止平凡解
model.compile("adam", lr=1e-3, loss_weights=[1.0, 100.0, 100.0])
losshistory, train_state = model.train(iterations=4000)
组件API 声明物理职能防错要点
传感器散点dde.icbc.PointSetBC将外部离散点作为软约束并入计算图输入坐标与观测值形状必须严格对齐 (N, 1)。
加权配置loss_weights=[1, 100, 100]多任务平衡第一位永远是 PDE，后续按边界列表顺序一一对齐！

3.3 物理先验与数据比例手算推演（Trace the Path）

◆ 欠阻尼能量耗散心智模型对齐

【实验数据】：传感器在 $t=0$ 测得 $u(0)=1.0$，在半周期 $t=\pi/\omega pprox 1.57$ 测得谷值 $u(1.57) = -0.73$。
物理方程：$\ddot{u} + \mu \dot{u} + 4u = 0$（质量为 1，刚度为 4，阻尼 $\mu$ 未知）。

【手算反演任务】：仅凭这两个点的数据与微分方程，手动反推阻尼系数 $\mu$ 的近似真值。

▸ 查看反演推演解答
1. 振幅包络按 $e^{-\gamma t}$ 衰减，在半周期处：$u(T/2) = -e^{-\gamma imes 1.57} = -0.73$；
2. 两边取自然对数：$-\gamma imes 1.57 = \ln(0.73) pprox -0.3147 \implies \gamma pprox 0.20$；
3. 由阻尼因子定义：$\gamma = \mu / (2m) \implies \mu = 2m \gamma = 2 imes 1.0 imes 0.20 = 0.40$！
核心震撼：这就是物理逆问题反演（Inverse Problem）的数学雏形！PINN 也是通过将 $\mu$ 声明为可训练张量，在几秒钟内自动完成这种逆向高精反演！

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

一位初学者在调用 PointSetBC 传入传感器数据时，传入了原生一维数组：

t_data = np.array([0.5, 1.0, 1.5])       # 形状为 (3,)
u_data = np.array([0.8, -0.2, -0.6])     # 形状为 (3,)
bc = dde.icbc.PointSetBC(t_data, u_data)  # 抛出 ValueError 或训练中广播暴增

【排错审问任务】：指出为什么科学计算神经网络要求输入永远保持两维矩阵 (N, 1)？

▸ 查看故障根因分析与修复代码

【失效机理】：在深度学习张量运算中，一维形状 (N,) 是没有特征维度的模糊向量，无法区分是“1 个包含 N 维特征的样本”还是“N 个包含 1 维特征的样本”。当与网络前向输出 (N, 1) 做均方差时，极易引发广播生成 $N imes N$ 的灾难性膨胀矩阵，导致 Loss 计算彻底失真。

【修复代码】：

t_data = t_data[:, None]  # 显式升维为 (3, 1)
u_data = u_data[:, None]
bc = dde.icbc.PointSetBC(t_data, u_data)

4.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当阻尼系数 $\mu o 0$ 时，系统能量严格守恒，相空间轨迹闭合为一个永远不收缩的对称正椭圆。
  • 极限二（趋近无穷大时）：当阻尼系数 $\mu o \infty$ 时，系统进入过阻尼死滞状态，完全失去一切波动性，直接单调指数衰减归零。
  • 极限三（物理实测噪声极限）：现实中传感器必然包含测量噪声。若 PointSetBC 权重给得过高（如 $10^6$），模型会强行扭曲自身去迎合噪声毛刺；合理的权重应该让物理方程充当低通滤波器，过滤掉传感器的高频白噪声。
