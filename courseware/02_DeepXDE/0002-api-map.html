2 · 致命深水区：Hessian 矩阵的二维张量索引陷阱

设输入空间为二维坐标：$\mathbf{x} = (x_0, x_1) = (x, y)$，输出标量物理场为 $u$。

黑塞矩阵（Hessian Matrix）是二阶偏导数组成的对称方阵：

$$H(u) = \begin{pmatrix} \frac{\partial^2 u}{\partial x_0^2} & \frac{\partial^2 u}{\partial x_0 \partial x_1} \\[6pt] \frac{\partial^2 u}{\partial x_1 \partial x_0} & \frac{\partial^2 u}{\partial x_1^2} \end{pmatrix} = \begin{pmatrix} H_{00} & H_{01} \\[6pt] H_{10} & H_{11} \end{pmatrix}$$
◆ 致命血泪 Bug 警示录 在很多人的直觉中，既然第一个自变量是 0，第二个自变量是 1，那么：
“求第一个自变量的二阶导写 (i=0, j=0)，那求第二个自变量的二阶导不就是写 (i=0, j=1) 吗？”
大错特错！
在 dde.grad.hessian(y, x, component=0, i=0, j=1) 中，参数 i 和 j 代表的是 Hessian 矩阵的第 i 行和第 j 列！
i=0, j=1 提取的是混合交叉偏导数 $\frac{\partial^2 u}{\partial x \partial y}$！它衡量的是流场的扭曲剪切，根本不是纵向曲率！
正确的纵向二阶纯导数 $\frac{\partial^2 u}{\partial y^2}$ 必须写成：i=1, j=1（第 1 行第 1 列的对角元素）！

3 · 工业级参考模版：二维稳态拉普拉斯算子严密声明

import deepxde as dde
import torch

# 声明二维直角坐标系下的拉普拉斯算子: d^2u/dx^2 + d^2u/dy^2 = 0
def pde_laplace_2d(x, y):
    # x[:, 0] 为 x 坐标，x[:, 1] 为 y 坐标
    # 1. 横向纯二阶导: d^2u / dx^2 (第 0 行第 0 列)
    u_xx = dde.grad.hessian(y, x, component=0, i=0, j=0)
    
    # 2. 纵向纯二阶导: d^2u / dy^2 (★ 必须是第 1 行第 1 列！)
    u_yy = dde.grad.hessian(y, x, component=0, i=1, j=1)
    
    # 3. 返回拉普拉斯残差
    return u_xx + u_yy
API 调用语法提取的数学偏导物理几何含义常见失误
jacobian(y, x, i=0, j=0)$\frac{\partial y_0}{\partial x_0}$水平速度梯度 $\partial u / \partial x$j 对应自变量坐标轴索引。
jacobian(y, x, i=0, j=1)$\frac{\partial y_0}{\partial x_1}$垂直速度梯度 $\partial u / \partial y$若为多输出场，i 对应场分量。
hessian(y, x, i=0, j=0)$\frac{\partial^2 y}{\partial x_0^2}$水平方向纯二阶曲率 $\partial_{xx} u$对角线元素。
hessian(y, x, i=1, j=1)$\frac{\partial^2 y}{\partial x_1^2}$垂直方向纯二阶曲率 $\partial_{yy} u$严禁误写成 i=0, j=1！

4 ·【主动提取与刻意练习】数理与代码工坊（Learning Opportunities）

【预测-观察-归因（POE 卡片）】多输入维度下 Jacobian vs Hessian 语法陷阱实验

【扰动情境】在二维空间 $(x_0, x_1)$ 中求解偏微分方程。工程师需要提取二阶偏导 $\frac{\partial^2 y}{\partial x_1^2}$。如果在代码中写成了 dde.grad.hessian(y, x, i=0, j=1)：

【请你先猜】这个 API 返回的是目标二阶导吗？

【实跑观测结果】
模型完全无法收敛，解的等高线云图发生诡异的 45 度对角线倾斜畸变！

【物理与数值归因】
i=0, j=1 提取的是 Hessian 矩阵的非对角非纯导分量——混合偏导数 $\frac{\partial^2 y}{\partial x_0 \partial x_1}$！真实的 $\frac{\partial^2 y}{\partial x_1^2}$ 在 Hessian 矩阵的第 2 行第 2 列，必须调用 i=1, j=1！这是所有 DeepXDE 开发者最易阵亡的深水坑！

4.3 多输出张量分量手算推演（Trace the Path）

◆ 速度矢量场多输出解剖

【系统定义】：二维流场具有两个速度分量 $\mathbf{u} = (u, v)$，网络输出维度为 2（y[:, 0] 代表 $u$，y[:, 1] 代表 $v$）。

【推演任务】：写出计算连续性方程散度 $\nabla \cdot \mathbf{u} = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y}$ 的具体两行 DeepXDE API。

▸ 查看单步推演标准解答
1. 水平速度对 $x$ 导数：du_dx = dde.grad.jacobian(y, x, i=0, j=0)（第 0 个输出对第 0 个自变量）；
2. 纵向速度对 $y$ 导数：dv_dy = dde.grad.jacobian(y, x, i=1, j=1)（第 1 个输出对第 1 个自变量）；
3. 散度残差：divergence = du_dx + dv_dy！

4.4 真实故障注入与排错诊断（Debug this!）

◆ 致命 Bug 诊断演练

一位研究员在配置多任务损失权重时写下了如下代码，程序抛出 IndexError: list index out of range：

# 问题包含 1 个 PDE 和 2 个边界条件 (总共 3 项损失)
model.compile("adam", lr=0.001, loss_weights=[1.0, 10.0])  # BUG!

【排错审问任务】：指出 loss_weights 的长度为什么必须与总损失项数严格一一对应？

▸ 查看故障根因分析与修复代码

【失效机理】：DeepXDE 在编译时会将问题的所有损失项排成一个全局平坦列表：[loss_pde, loss_bc1, loss_bc2, ...]。框架在加权求和时会严格通过下标 loss_weights[i] 提取对应系数。如果列表长度少于损失项数量，直接触发列表索引越界崩溃！

【修复代码】：

model.compile("adam", lr=0.001, loss_weights=[1.0, 10.0, 10.0])

5.1 禁黑话 3 句话口述挑战

【向高中生解释】：为什么在平面上算弯曲程度，除了算前后弯、左右弯，还必须算一个斜着拧麻花的量？

【严禁出现词汇】：黑塞矩阵、混合偏导、微分几何、张量、正交基

▸ 查看费曼级满分通俗解答范例
“如果一张纸只是向上卷成圆筒，你只需要量出它前后方向有多弯；但如果你拿着毛巾的两头朝相反方向用力拧，毛巾不仅变弯，整张布面还会斜着拧出一条条麻花一样的旋转褶皱。这个‘斜着拧’的动作在任何单一方向都测不出来，必须同时测量横向和纵向是如何互相扭在一起的。”

5.2 极端参数极限三问（Extreme Limits）

  • 极限一（趋近 0 时）：当边界点采样数 num_boundary = 0 时，问题丧失定解条件，数学上解非唯一。
  • 极限二（非线性优化切换极限）：Adam 优化器擅长逃离鞍点，但在一阶平缓平原上收敛极其缓慢；L-BFGS 二阶拟牛顿法利用二阶曲率信息，能在十几步内将残差从 $10^{-3}$ 强力压降至机器极限 $10^{-8}$！两阶段结合是工业收敛标准范式。
  • 极限三（几何奇异凹角点）：若计算域包含 L 形凹角，根据弹性力学理论，凹角顶点处应力集中导致导数趋向无穷大，常规点配点采样必须配合奇异基函数或局域自适应加密。

5.3 货物崇拜排查（Cargo Cult Detection）

【深层审问】：为什么很多人在用 DeepXDE 时，一开始就直接上 L-BFGS 二阶优化器，结果算例一瞬间就报错崩溃或陷入死循环？

【真实底层】：因为 L-BFGS 依赖局部二次型泰勒展开！在训练最早期，网络权重完全随机，损失曲面极度崎岖且充满高度非凸噪声，此时的二阶曲率估计完全是南辕北辙的虚假信息，会导致 L-BFGS 的线搜索步长直接步入悬崖！工业最佳实践是：先用 Adam 跑 1000~3000 步将系统推进至平缓的局部凸洼地，再召唤 L-BFGS 执行二阶致命绝杀！
